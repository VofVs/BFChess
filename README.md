# Battlefield Chess

Mobile-first deterministic battlefield strategy prototype.

## iPhone
Open the GitHub Pages site in Safari, tap **Share → Add to Home Screen**, then launch it from the Home Screen. It caches for offline play after the first successful load.

Current build: **v0.17.1** — full-board iPhone UI, 2-minute match clock, pause menu, rules/M·A·S reference, persistent personal best and W/L/D stats, three-piece army cap, improved North deployment behavior, and the iPhone UI/cache hotfix.
