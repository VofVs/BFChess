# Battlefield Chess

Mobile-first deterministic battlefield strategy prototype.

## iPhone
Open the GitHub Pages site in Safari, tap **Share → Add to Home Screen**, then launch it from the Home Screen. It caches for offline play after the first successful load.

Current build: **v0.18** — full-board iPhone UI, upward-counting match stopwatch, pause menu, rules/M·A·S reference, persistent personal best and W/L/D stats, three-piece army cap, improved North deployment behavior, and the iPhone UI/cache hotfix.

The stopwatch is informational only: it records match duration and personal-best victory times, but it does not decide wins or losses.
